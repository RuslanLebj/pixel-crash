# КРАШ! — пиксельная авторазборка, v2

Откройте `index.html` в браузере — установка и сервер не нужны.

## Режимы

- **Свободный заезд** — без таймера и автоматического финиша. Опция «Неуязвимая машинка» отключает урон; её можно переключать во время заезда.
- **90 секунд** — разрушьте 65% двора, сохранив машину. Рекорды режимов хранятся отдельно в браузере.

Переключение режима начинает новый заезд. R восстанавливает двор.

## Управление

W / ↑ — газ, S / ↓ — тормоз и задний ход, A D / ← → — поворот, пробел — ручник для заноса. P / Escape — пауза, R — заново. Для сенсорного экрана есть кнопки.

## Что изменилось

- Независимые направление кузова и скорость, инерция, плавный руль и управляемый занос.
- Дым шин и следы, повреждения кузова, дым двигателя при низкой прочности.
- Обломки с высотой, вращением и отскоками. Машина расталкивает их; быстрые обломки повреждают препятствия.
- Частично разрушенные секции стен обваливаются. Взрывные бочки создают цепные реакции и отбрасывают машину и обломки.

## Разработка

Исходники: `dist/index.html`, `dist/game.js`. После правок соберите самостоятельный HTML:

```sh
python3 scripts/build-standalone.py
```

Проверка игровой логики (Node.js, без зависимостей):

```sh
node tests/game.test.cjs
```
