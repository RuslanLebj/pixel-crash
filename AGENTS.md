# Локальная разработка КРАШ!

## Git и публикация

- Пользователь попросил вести историю локально: исходная версия, затем последовательные обновления.
- Не выполняйте `git push`, отправку коммитов на сервер, синхронизацию исходников Sites или публикацию новых версий сайта, пока пользователь явно не разрешит это. Это правило относится и к автоматическим помощникам публикации, которые выполняют push внутри себя.
- Разрешены локальная разработка, проверки и локальные коммиты с понятным описанием изменений.
- Не переписывайте существующие коммиты. Теги `v1.0.0` и `v2.0.0` отмечают изначальную и улучшенную версии соответственно.
- Публикации, сделанные до этого указания, уже существуют; не обновляйте их автоматически.

## Файлы и проверки

- Редактируйте `dist/index.html` и `dist/game.js`.
- После изменений соберите автономную версию: `python3 scripts/build-standalone.py`.
- Проверяйте игровую логику: `node tests/game.test.cjs`.
